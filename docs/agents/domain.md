# Domain Docs

Single-context repo. Before exploring any area of the codebase, read:

- **`CONTEXT.md`** at the repo root — domain glossary and vocabulary rules
- **`docs/adr/`** — architectural decisions that must not be re-litigated without justification

If a concept you need isn't in the glossary, it's a signal: either you're inventing language the project doesn't use (reconsider), or there's a real gap (note it for `/grill-with-docs`).

If your output contradicts an existing ADR, surface it explicitly rather than silently overriding it.
